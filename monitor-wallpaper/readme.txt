モニターごとに壁紙をランダムに変える
====================================

Windows 11 / 10 用です。追加ソフトや管理者権限は不要です。
このフォルダーを丸ごと、普段使う場所に置いてください。
ZIP で受け取った場合は、右クリックして「すべて展開」してから使います。

最初の設定
----------
1. Windows の「設定 → システム → ディスプレイ」で「識別」を押すと、
   画面に 1、2 などの番号が出ます。2画面は「表示画面を拡張する」で使います。

2. Windows の「設定 → 個人用設定 → 背景」で「画像」を選びます。
   画像は各画面に表示する設定にしてください。1枚の画像を全画面に
   またがって表示する設定では、画面ごとに変更できません。

3. config.txt をメモ帳で開きます。最初は両方の画面が keep です。
   モニター1だけを変える場合は、次のように書きます。

   Monitor1 = random
   Folder1 = C:\Pictures\Wallpapers

   Monitor2 = keep
   Folder2 =

   random はフォルダーから画像をランダムに選び、keep は今のままです。
   自分のパソコンの画像フォルダーの場所を Folder1 に貼り付けます。
   画像フォルダーをエクスプローラーで開き、上のアドレス欄をクリック
   すると、場所をコピーできます。空白や日本語のある場所も使えます。

   モニター2も変えたい場合は Monitor2 を random にして、Folder2 にも
   フォルダーの場所を書きます。両方に同じフォルダーを使うこともできます。
   画面の番号が 5 なら、Monitor2 と Folder2 の数字を 5 に書き換えます。
   config.txt に書いていない画面も、今の壁紙のままです。
   使える画像はフォルダー直下の JPG、JPEG、JFIF、PNG、BMP です。
   今の壁紙が候補にある場合、別の候補があればそちらから選びます。

4. 保存したら Reroll.bat をダブルクリックして、今すぐ試せます。
   気に入らなければ、同じファイルをもう一度開くだけです。

Windows にサインインするたびに変える
------------------------------------
Setup.bat をダブルクリックします。次回の Windows サインイン時から、
壁紙が1回引き直されます。設定を変えるときは、設定ファイルを保存するだけで
反映されます。
自動実行だけを止めたいときは StopStartup.bat を開きます。

以前のフォルダーから引っ越すとき
--------------------------------
設定ファイルを移動先のフォルダーにコピーし、移動先の Setup.bat を開きます。
以前のサインイン時の登録が置き換わります。タスクバーにピン留めしていた場合は、
ピン留めをやり直します。

Git で使う場合は、config.txt のコピーを同じフォルダーに config.local.txt として
保存できます。こちらが優先され、Git のコミット対象から外れます。

タスクバーから引き直す
----------------------
Setup.bat を一度実行してから、スタートで「壁紙を引き直す」を検索します。
検索結果を右クリックし、「タスクバーにピン留めする」を選びます。
ピン留めできない場合も、スタートの検索結果や Reroll.bat から実行できます。

うまくいかないとき
------------------
・Reroll.bat を開くと、問題があれば画面に理由が表示されます。
・自動実行の結果は、エクスプローラーのアドレス欄に次の1行を貼り付け、
  Enter を押すとメモ帳で確認できます。
  %LOCALAPPDATA%\MyTools\MonitorWallpaper\last-startup.txt
・自動実行の記録が作られない場合は、タスク マネージャーの
  「スタートアップ アプリ」で「My Tools Monitor Wallpaper」が有効か確認します。
